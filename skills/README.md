# Skills

Skills live in bucket folders under this directory, one folder per skill:
`skills/<bucket>/<skill-name>/SKILL.md`.

Buckets are organized by role, not by topic:

- [core](./core/README.md) - shared setup
- [po-pm](./po-pm/README.md) - PRD -> epic -> user-stories -> sync-to-tracker pipeline
- [developer](./developer/README.md) - spec-then-implement workflow

`scrum-master/` is planned but not yet created - see the design spec's
Appendix (`docs/superpowers/specs/2026-08-21-qsbn-workflow-design.md` in the
`vampire-coder-skills` project) for the agreed shape.

Each bucket folder has its own `README.md` listing the skills in it with a
one-line description (see `CLAUDE.md` at the repo root for the `SKILL.md`
frontmatter contract).
