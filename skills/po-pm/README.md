# po-pm

The Product Owner / Project Manager pipeline: PRD -> epic -> user stories ->
sync-to-tracker.

## Skills

- **[qsbn-prd](./qsbn-prd/SKILL.md)** - Interview the user about a feature and write its PRD, bootstrapping the whole-product PRD on first use.
- **[qsbn-propose-epic](./qsbn-propose-epic/SKILL.md)** - Match a feature to an existing epic or propose a new one, then move it there (or reassign it later).
- **[qsbn-user-stories](./qsbn-user-stories/SKILL.md)** - Write INVEST-checked user stories with Given/When/Then acceptance criteria for an epic-assigned feature.
- **[qsbn-sync-to-tracker](./qsbn-sync-to-tracker/SKILL.md)** - Create or update a feature's epic and stories in the configured tracker. Azure DevOps only for now.
