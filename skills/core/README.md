# core

Shared foundation used by every other bucket.

## Skills

- **[qsbn-setup](./qsbn-setup/SKILL.md)** - Configure tracker connection, submodule layout, story tag, and third-party skill preferences. Run once per repo.
- **[qsbn-docs](./qsbn-docs/SKILL.md)** - Scout every code submodule and generate or refresh `docs/architecture.md` and `docs/project-overview.md` for the whole project, one pair of documents, never one per submodule.
